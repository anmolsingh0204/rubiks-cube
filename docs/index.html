Built for Makers & Solvers

True Cubie Geometry

Each of the 26–98 cubies is individually rendered with visible gaps and edge lines, revealing the internal structure like never before.

3D Printing Ready

Export STL/OBJ with per-face color groups for multi-material printers (Bambu AMS, Prusa MMU) or paint-after-print workflows.

Any Size N×N×N

Generate cubes from 2×2×2 to 7×7×7 and beyond. Exploded view mode separates every cubie for complete visibility.

Solver Framework

Built-in CubeState class with facelet representation, move notation, and scrambling — ready for animation and solving algorithms.

Interactive WebGL

Plotly-powered WebGL rendering with orbit controls, dynamic lighting, and 60fps performance on any device.

Dark/Light Mode

Automatic theme detection with manual override. Cubes and UI adapt beautifully to both light and dark environments.
